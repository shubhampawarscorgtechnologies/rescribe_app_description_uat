What this replaces

Hospitals run on printed forms — consent sheets, nursing notes, treatment charts, referral slips. Traditionally these are filled by hand, then scanned back in, or never digitised at all. Paperless Documentation keeps the handwriting and removes the paper: the form opens on the device, the clinician writes on it with a stylus or finger, and the finished page is stored against the patient's visit.

STEP 1 Document list Documents grouped by category and sub-category. Select, print, email or send on WhatsApp. STEP 2 History screen Everything filed under a sub-category. Upload, create new, edit or view earlier documents. STEP 3 Preview screen Page-level control before it goes out — edit, delete, refresh, print, activity logs. STEP 4 Canvas screen The writing surface. Pen, eraser, highlighter, shapes, overlays, stamps, copy tools.

Where it opens from. Doctor app: Admitted Patients List → patient → Pen Mode, and Search → Visit List → a visit → Pen Mode (for patients seen earlier). Nurse app: the bed on the Bed Display screen → Pen Mode. The screens after that point are identical in both apps.

Step 1

Document list

All documents for the patient, grouped by category and then sub-category. Grouping, display order and colour coding are managed per hospital, so each site sees its own paperwork organised its own way.

Element What it does Why it matters
Category The top grouping of documents. Keeps a long list navigable.
Sub-category The specific document type inside a category. This is what opens the History screen.
Sequence order The order categories and sub-categories appear in. Puts the most-used forms at the top for that hospital.
Colours Colour assigned to a category or sub-category. Fast visual identification during a busy round.
View all documents Shows everything on the patient in one list. When you don't know which category it was filed under.
Select documents Multi-select, then output the selection. Sending a set of forms together rather than one at a time.

Sharing a selection

Print PDFProduces a PDF of the selected documents for printing or filing.
Send over emailEmails the selected documents out of the app.
Send over WhatsAppShares the selected documents through WhatsApp.

Role permissions

Adding, editing, deleting, viewing, printing, e-mailing and WhatsApp sharing are each controlled by a Patient Document permission on the user’s role. An action the role does not carry is shown greyed out and does not respond to a tap — on this screen, on the History screen, in the preview and on the canvas. Permissions are read from the server after sign-in and refreshed on the dashboard; the last known set is used while offline. Full walkthrough: What’s New → Document actions follow role permissions.

Patient data leaves the hospital at this point. Email and WhatsApp send clinical documents to an outside service. Whoever operates the app is responsible for sending to the right recipient, and hospitals should confirm this matches their own data-sharing policy before enabling it for staff.

Step 2

History screen

Opening a sub-category shows everything already filed under it for this patient, and offers the four ways to add or change a document.

Action What it does Typical use
Upload from gallery Brings in an image already stored on the device. A form photographed earlier, or a report received as a picture.
Upload from camera Takes a photo now and files it as a document. Capturing a paper form that arrived from outside.
Upload with geo tag Takes a photo and records the location with it. Proof of where the document was captured — home visits, field work.
Create new document Opens a blank document on the canvas. Writing a fresh note or filling a blank form.
Edit previous document Reopens an existing document on the canvas. Adding to a chart already started.
View previous document Opens it read-only. Checking what was written without risking a change.

Step 3

Preview document screen

The checkpoint between writing and sharing. Page-level control, plus the audit trail.

Control What it does
Edit page Sends the page back to the canvas for more writing.
Delete page Removes a page from the document.
Refresh Reloads the document so the latest saved version is shown.
Investigation Brings investigation data alongside the document.
Print PDF Produces the PDF of the document.
View activity logs Shows who did what to this document and when.

Activity logs are the accountability record. Because clinical documents are edited by more than one person, the log is what answers "who changed this page and when". Point support queries about unexpected content here first.

Step 4

Canvas screen

The writing surface, and the largest part of the feature. Grouped below by what the clinician is trying to do.

4.1 Drawing

Tool What it does
Edit using pen Writing with a stylus — the closest thing to a pen on paper.
Edit using fingers Writing or marking with a fingertip when no stylus is at hand.
Eraser Removes strokes. Eraser size is adjustable for fine corrections or clearing an area.
Highlight Marks existing content without covering it.
Brush settings Colour and draw settings for writing and colouring.
Shapes Draws a triangle, circle, square or line — for boxing values or marking a diagram.

4.2 Pages and view

Control What it does
Zoom Magnifies the page for small handwriting and detailed marks.
Add new page Extends the document when one page is not enough.
Delete page Removes a page from the document.
Print saved page Prints the page as saved.
Page slider Tapping the Page n / n chip opens a slider under the page; dragging it and letting go jumps straight to that page. Shown on documents of three pages or more, and hides itself a few seconds after the last touch.

4.3 Undo, redo, revert

Control What it does Scope
Undo actions Steps back through recent strokes and edits. Since the page was opened.
Redo actions Re-applies something just undone. Since the page was opened.
Revert to last saved Discards current changes and returns the page to its last saved state. The whole page.

4.4 Copy tools

Repeated paperwork is the norm on a ward — the same observations, the same layout, day after day. These three tools exist so a clinician does not redraw what they already drew.

Tool What it does Use it when
Copy & paste & replace page content Copies content and replaces what is currently on the target page. Starting the new page from a known-good layout.
Copy & paste complete page Duplicates a whole page into the document. Same form, next day.
Copy & paste selected content Copies only a selected part of the page. Carrying one table or one block across.

4.5 Reference panels

Draggable panels that sit next to the page, so the clinician can read information while writing rather than leaving the canvas to find it.

Panel Shows
View other documents Another document from the same patient, for reference while writing.
Patient info The patient's identity and admission details.
Activity logs Who acted on this document and when.
Investigation history Earlier investigations and their results.

4.6 Overlays placed on the page

Items dropped onto the document itself. Between them they cover the three things handwriting alone cannot do: prove identity, prove provenance, and carry an image.

Camera photoPlaces a photo taken on the spot onto the page.
Camera with geoPhoto plus the location it was taken at.
UHID barcodeThe patient's permanent hospital ID as a scannable barcode.
Visit ID barcodeBarcode identifying this specific visit or admission.
QR codeScannable code carrying the document's reference.
Patient imageThe patient's photo on the document.
Patient infoIdentity and admission details printed onto the page.
Doctor stampsThe doctor's stamp, in place of a physical rubber stamp.
FingerprintThe patient's or attendant's thumb impression, taken from a USB scanner.

Why barcodes matter: a printed page with a UHID and visit-ID barcode can be scanned back into the system without anyone typing a number. Keep barcodes clear of handwriting — anything drawn across a barcode or QR code can stop it scanning.

4.7 Fingerprint capture

Replaces the inked thumb impression on consent forms, admission papers and discharge summaries. The scanner plugs into the tablet with a USB OTG cable; the impression is taken live and dropped onto the page as an overlay, so it can be positioned over the signature block exactly like a stamp.

  1. Open the overlay menuOn the canvas toolbar, tap the overlay button. The “Choose one” sheet opens.
  2. Tap FingerprintLast option in the top row of the sheet, beside Patient Image.
  3. Place the finger on the scanner“Place finger on scanner…” appears while the device is being prepared. The first capture after the tablet is switched on also asks for permission to use the scanner — allow it.
  4. Check the impressionThe captured print is shown for approval: Insert to accept, Retry to take it again, × to cancel without placing anything.
  5. Position it on the pageAfter Insert, the fingerprint appears on the document and can be dragged anywhere and resized — normally into the patient / attendant signature box.

Supported scanner: Mantra MFS500 (recommended, tested). Secugen Hamster models are also supported. Connect the scanner before tapping Fingerprint — if nothing is plugged in, the app reports “No fingerprint scanner connected.”

What is stored: the fingerprint is placed on the document as a picture of the impression, exactly like a stamp or a photo. Nothing is matched against Aadhaar and no biometric identity check is performed.

If the print looks partial: that is the size of the scanner window, not a fault — these sensors image the pad of the fingertip, not the whole finger. Press the finger flat and centred, and keep the sensor surface clean; use Retry until the ridges read clearly.

In practice

The three flows worth demonstrating

Almost everything staff do with this feature is one of these three. A training session should walk each one end to end.

Flow A — Write a new document at the bedside

  1. Open Pen ModeDoctor: admitted patient → Pen Mode. Nurse: bed → Pen Mode.
  2. Pick the paperworkDocument list → category → sub-category.
  3. Create new documentHistory screen → Create new document. The canvas opens.
  4. Write itPen or finger, eraser and highlighter as needed; add a page if one is not enough.
  5. Stamp and identifyPlace patient info, UHID / visit barcode and the doctor stamp. On a consent or admission form, take the patient's fingerprint here too.
  6. Check and closePreview screen — read the pages, then print or leave it filed against the visit.

Flow B — Continue yesterday's chart

  1. Reopen the documentHistory screen → Edit previous document.
  2. Carry the layout overCopy & paste complete page, or copy only the selected block that repeats.
  3. Add today's entriesWrite on the new page; keep the reference panel open for the earlier document.
  4. Correct safelyUndo for a slip; Revert to last saved if the page needs to go back to how it was.

Flow C — Send documents out

  1. Select what goesDocument list → select the documents required.
  2. Choose the routePrint PDF for the file, email or WhatsApp for the recipient.
  3. Confirm the recipientClinical documents leaving the hospital cannot be recalled — check the address or number before sending.
Behaviour

Working without network

Wards and clinic rooms have dead spots, and documentation cannot wait for signal.

  • Writing: pages written offline are saved on the device and placed in a sync queue.
  • Recovering: when the device is back on network, queued documents upload on their own.
  • Checking: the Menu screen in both apps lists anything still pending under View Sync Pending Offline Data.
  • The one risk: clearing cache or logging out while documents are still pending. Check the pending list first.
